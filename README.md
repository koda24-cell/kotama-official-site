# コタマのぼうけん — 公式サイト

ブラウザRPG『コタマのぼうけん』の**独立した紹介サイト**です。ゲーム本体のソースコードは含みません。

- `index.html`: 公式サイト
- `site-config.js`: 「ゲームを始める」ボタンの遷移先（ゲーム本体の別URL）
- `assets/`: 公式サイトで使用するキャラクター画像のみ

## 公開前の確認

1. `site-config.js` の `gameUrl` が実際に利用できるゲームURLか確認する（現時点では候補URL）。
2. PC・スマートフォンで表示確認する。
3. 画像が表示されるか確認する。モンスター画像は元ファイルが空だったため現在はプレースホルダー。
4. サイトを検索結果に表示する場合は `index.html` の `noindex,nofollow` を外す。
5. ゲーム本体のアクセス制限はゲーム側で行う。URLの秘匿だけでは制限にならない。

現在このリポジトリは **Private**。GitHub Pages等の公開設定は未実施です。
